Este repositorio alberga una aplicación simple de lista de tareas (To-Do List), desarrollada como proyecto de Aprendizaje Basado en Proyectos (ABP) con enfoque en el Aprendizaje Colaborativo.

La elección de una aplicación tan simple como una "To-Do List" es intencional, ya que su familiaridad y sus operaciones básicas (crear, leer, actualizar y eliminar) permiten a los participantes enfocarse por completo en el proceso de desarrollo y la gestión de versiones, en lugar de perderse en complejidades técnicas del código.

El objetivo principal fue simular un entorno de desarrollo profesional para comprender y aplicar el flujo de trabajo completo de Git (ramificación, integración y gestión de versiones).
